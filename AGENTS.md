# Repository Instructions

- Keep one fault per file in `test-data/invalid/`. Add a test case in
  `tests/shapes.test.ts` for each new file.
- If you change `tests/support/bcfOWL.ttl`, copy it from the bcfOWL repository.
  Do not edit it here.
- Load and follow the `simple-english` skill before you create or change
  technical prose. Use the pragmatic mode by default.
- Run `npm run validate` before you finish a change.
